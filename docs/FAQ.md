# 常见问题

## 1. 这个项目要钱吗？

项目源码是公开仓库，可以下载自己运行。运行本身不收费，但使用真实 DeepSeek/Kimi API 时，
模型供应商会按照你的账号计费。项目内置费用预算，防止单局或每日无上限消耗。

## 2. 怎么下载？

推荐 Git 克隆：

```bash
git clone https://github.com/XiaoYu-yu/moonlit-werewolf.git
cd moonlit-werewolf
```

也可以打开仓库页面，点击绿色 `Code` 按钮，选择 `Download ZIP`。

## 3. 下载 ZIP 后怎么启动？

需要先安装 Node.js 24+。

Windows：双击 `一键启动狼人杀.cmd`，然后访问 `http://localhost:3000`。

macOS/Linux：按照 `docs/GETTING_STARTED.md` 手动安装依赖并启动。

## 4. 创建房间的邀请码是什么？

开发环境使用：

```text
MOONLIT-DEV
```

生产部署时由管理员在后台配置真实邀请码。

## 5. 不配置 AI 密钥能玩吗？

能。AI 会使用服务端确定性规则兜底完成发言、夜间行动和投票，不会卡死对局。
但发言会变成规则生成的固定内容，而不是真实模型输出。

## 6. 怎么让 AI 使用 DeepSeek 或 Kimi？

Windows 双击 `配置AI模型.cmd` 并粘贴密钥。手动部署时在 `.env` 中设置：

```text
DEEPSEEK_API_KEY=...
KIMI_API_KEY=...
```

真实密钥只能放在服务端，不能写成 `NEXT_PUBLIC_*`。

## 7. 为什么 AI 一直显示“规则兜底”？

可能原因：

- 没有配置对应供应商密钥。
- 供应商请求超时。
- 返回格式不合法或行动与角色冲突。
- 预算已耗尽。
- 服务端网络无法访问供应商 API。

## 8. 怎么让朋友加入？

同一局域网或同一公网服务器运行后，把 Web 地址和房间码发给朋友。公网访问需要部署到
VPS 并配置 HTTPS。

## 9. 可以部署到 GitHub Pages 吗？

不适合。本项目是完整 Web 应用，包含 Next.js 服务端、NestJS API、Socket.IO、数据库和
Redis，不是纯静态页面。需要 Docker 服务器。

## 10. 数据会保存吗？

本地开发默认使用内存模式，重启后房间会消失。生产部署使用 PostgreSQL 保存模型配置等
数据；进行中的房间状态目前仍是单 API 进程内存实现。

## 11. 为什么我看不到别人的角色？

这是服务端隐私边界。每个玩家只能看到自己的私有状态；普通玩家无法查看其他玩家身份，
也无法查看 AI 隐藏分析。只有 AI 观战局的房主可以看到全知状态。

## 12. 有开源许可证吗？

目前仓库没有添加开源许可证，默认保留所有权利。可以下载学习，但使用、修改和再分发
的权利尚未开放。如果作者添加许可证，会在 README 中更新。

## 13. 我想贡献代码怎么办？

请阅读 `docs/CONTRIBUTING.md`。先 Fork 仓库，创建分支，提交修改，然后发起 Pull Request。
